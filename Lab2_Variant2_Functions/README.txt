Лабораторная работа 2 — Вариант 2

Запуск: python main.py

main.py — функции для заданий 1–6
utilities.py — чтение CSV/XML и запись текстовых файлов
books-en.csv — исходные данные книг
currency.xml — исходные данные валют
output.txt — все результаты заданий 1–6 (создается автоматически)
bibliography.txt — 20 библиографических ссылок (создается автоматически)

Для поиска другого автора измените author = "Grisham" в функции main().
Выводы записываются в output.txt, а не в консоль.
